# Money Calculator

Локальное десктопное приложение для расчёта доходов и расходов. Работает без
интернета и без регистрации, все данные лежат в одном текстовом файле JSON.

## Возможности

- **Сессии** — отдельные расчёты (месяц, поездка, проект). Создание,
  переименование, изменение периода, валюты и заметки, удаление.
- **Участники** — люди внутри сессии; доходы и расходы можно привязывать к
  каждому, чтобы видеть личный баланс.
- **Доходы** — сумма, источник, дата, участник и комментарий.
- **Расходы** — структурно: вид расхода → тип расхода, плюс сумма, дата,
  участник и комментарий. Новый тип можно ввести прямо в диалоге расхода — он
  добавится в справочник вида.
- **Категории** — управление видами расходов и их типами. Новые сессии уже
  содержат набор стандартных видов.
- **Сводка** — итоги по доходам, расходам и балансу, а также разбивка по
  участникам и видам расходов.
- Автосохранение после каждого изменения.

## Запуск

Требуется Python 3.10+ с Tkinter (входит в стандартный установщик Python для
Windows). Внешние библиотеки не нужны.

```bat
run.bat
```

или

```bat
python app.py
```

Можно указать свой файл данных:

```bat
python app.py --data D:\Money\data.json
```

## Где хранятся данные

По умолчанию:

```
%APPDATA%\MoneyCalculator\data.json
```

Путь всегда виден в нижней строке окна, рядом есть кнопка «Открыть папку».
Файл — обычный JSON с отступами, его можно читать и редактировать вручную.
Запись атомарная: сначала во временный файл, затем замена основного, поэтому
сбой не оставит «половину» данных. Если файл повреждён, при запуске создаётся
резервная копия `data.corrupt-*.json`, а приложение открывается с пустыми
данными.

## Структура проекта

```
app.py                 точка входа и разбор аргументов
run.bat                запуск в Windows
moneycalc/
  app.py               главное окно, вкладки, действия
  dialogs.py           модальные диалоги
  models.py            модель данных и сериализация
  storage.py           чтение/запись JSON
  formatting.py        суммы, даты, склонения
  theme.py             палитра, шрифты, стили ttk
  widgets.py           карточки, прокрутка, таблица
```
